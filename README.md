# GFL2 리몰딩 플래너

소녀전선2: 망명 **리몰딩(성장 데이터) 최적 배치 계산기** — 보유 리몰딩을 등록하면 파티 단위로 최적 장착 조합을 자동으로 찾아줍니다.

## 다운로드

👉 **[Releases](../../releases/latest)** 에서 최신 exe를 받으세요. 설치 불필요(포터블), 실행하면 바로 사용 가능합니다.

> **SmartScreen 안내**: 개인 개발 도구라 코드 서명이 없어 "Windows의 PC 보호" 경고가 뜰 수 있습니다.
> `추가 정보 → 실행`으로 진행하면 됩니다. 네트워크 통신 없음(완전 오프라인 동작), 데이터는 전부 로컬 저장.

## 주요 기능

- **보유 리몰딩 등록** — 스크린샷 1장 클릭 인식(OCR) 또는 [gfl2logger](https://github.com/blead/gfl2logger) CSV/JSON 임포트 호환
- **파티 자동 배치** — 인형 60종 전체 데이터(스탯·코어·결합키·전용무기·파츠) 내장, 만작 기준 기대 딜 최적화
  - 현상(꽃) 활성 > 피와 칼의 전환(캡 5) > 위키 추천 매칭 > 기대 딜 순 사전식 우선
  - 시너지 전담 서포터 자동 지정(공격 협동 예약), 파티 공버프 꽃(중첩 불가)은 후미 인형이 전담
  - 헬렌·안도리스 방어→공격 전환, 류시·스프링필드 가중 공격(체력 계수), 안도리스 방어형 세팅 지원
- **보유 레포트** — 속성×주옵션 히트맵, 명품(속성 강타 Lv3) 집계, 파밍 추천
- **검색** — '피칼' 같은 통용 약어 지원

## 사용 순서

1. 실행 → 상단에서 파티에 인형 배치
2. 리몰딩 등록: 인게임 리몰딩 화면 스크린샷을 붙여넣거나, gfl2logger 추출 파일 임포트
3. **파티 전체 배치** 클릭 → 슬롯별 최적 장착과 기대 딜이 표시됩니다

## 데이터 기준

- 나무위키 소전2 문서(인형 60종) 크롤링 + 실계정 실측 검증(스탯 분해 일치 확인)
- 만작(코어 만렙·결합도 9·파츠 풀보정) 가정 — 개별 스탯은 인형 설정에서 수동 보정 가능
