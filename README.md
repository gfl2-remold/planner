# GFL2 리몰딩 플래너

소녀전선2: 망명 **리몰딩(성장 데이터) 최적 배치 계산기** — 보유 리몰딩을 등록하면 파티 단위로 최적 장착 조합을 자동으로 찾아줍니다.

## 바로 사용

👉 **https://gfl2-remold.github.io/planner/**

설치·다운로드 없이 브라우저에서 바로 사용. 데이터는 브라우저(localStorage)에 저장됩니다.

## 주요 기능

- **보유 리몰딩 등록** — 화면 인식 세팅 후 직접 클릭, 앱플레이어 매크로기능을 이용해서 리몰딩 전량 스캔
- **파티 자동 배치** — 인형 60종 전체 데이터(스탯·코어·결합키·전용무기·파츠) 내장, 만작 기준 기대 딜 최적화
  - 현상(꽃) 활성 > 피와 칼의 전환(캡 5) > 위키 추천 매칭 > 기대 딜 순 사전식 우선
  - 시너지 전담 서포터 자동 지정(공격 협동 예약), 파티 공버프 꽃(중첩 불가)은 후미 인형이 전담
 
- **보유 레포트** — 속성×주옵션 히트맵, 파밍 추천
- **검색** — '피칼' 같은 통용 약어 지원

## 사용 순서

1. 실행 → 상단에서 파티에 인형 배치
2. 리몰딩 등록: 화면 인식 세팅 후 직접 클릭, 앱플레이어 매크로기능을 이용해서 리몰딩 전량 스캔하거나 gfl2logger 리몰딩정보 추출 파일 임포트
3. **파티 전체 배치** 클릭 → 슬롯별 최적 장착과 기대 딜이 표시됩니다

## 데이터 기준

- 나무위키 소전2 문서(인형 60종) 크롤링 + 실계정 실측 검증(스탯 분해 일치 확인)
- 풀돌풀재(코어 만렙·결합도 9·파츠 풀보정) 가정 — 개별 스탯은 인형 설정에서 수동 보정 가능
